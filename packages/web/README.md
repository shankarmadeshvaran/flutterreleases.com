# @flutterreleases/web

React + Vite frontend for [flutterreleases.com](https://flutterreleases.com).

## Dev

```sh
bun run dev       # http://localhost:5173
```

## Build

```sh
bun run build     # outputs to dist/
```

## Typecheck

```sh
bun run typecheck
```

See root [README](../../README.md) for full project docs.
